사용 규칙

  • 이 지도는 위치 라우터(WHERE 전용) — 스케줄·의존성=architecture wiki, 함정·장애 이력=개별 메모리, 데이터셋 상세=datalake catalog
  • 지도는 힌트다. 파괴적 작업(덮어쓰기·삭제·배포) 전에는 지도가 가리킨 대상 1건만 preflight 실재 확인(test -e / Test-Path / git show). 실패해도 전역 grep으로 돌아가지 말고 지도가 지정한 한 디렉토리 안에서만 확인
  • 경로·위계·정본을 바꾼 작업은 이 지도 갱신까지가 완료다 (write-through)
  • 주 1회(일 22:10 KST) 맥미니 crontab 잡(map-weekly)이 최근 8일 메모리 변경 + 실재 검증 결과로 자동 갱신. 수동 갱신도 허용
  • 상한: 220줄 / 28KiB — 넘으면 상세를 registry·catalog·개별 메모리로 밀어낼 것

위험 플래그

  • H1 @repo 트리는 5분마다 git checkout -- "*.html"+pull — 미커밋 변경 소멸 → 맥미니 수정=한 SSH 체인에서 즉시 commit+push([skip ci])

  • H3 wrap.html = gh-pages 전용(main 미추적) — 로컬/main에서 찾지 말 것, 검증=라이브 URL
  • H4 ~~VM→맥미니 이전 중~~ → 8/3 완료. 봇·타이머 primary=맥미니 launchd. VM 경로(/home/ubuntu/…)를 가리키는 문서·스크립트는 scripts/vm_legacy/의 역사물
  • H5 @work 날짜 폴더(YYMMDD_*)는 동적 — 전역 grep 금지, 해당 <부류> 디렉토리만 한정 검색
  • H6 맥미니 정본은 맥미니에서 직접 작업(로컬 개발→scp 금지). 부득이 scp push 시 양쪽 mtime 대조(8/7 스테일 덮어쓰기 사고)
