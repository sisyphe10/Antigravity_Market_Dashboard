위험 플래그

  • H1 @repo 트리는 5분마다 git checkout -- "*.html"+pull — 미커밋 변경 소멸 → 맥미니 수정=한 SSH 체인에서 즉시 commit+push([skip ci])
  • H2 @srv/dashboard/current = 게시 스냅숏 — 직접 수정 금지, 생성기를 고쳐서 재생성
  • H3 wrap.html = gh-pages 전용(main 미추적) — 로컬/main에서 찾지 말 것, 검증=라이브 URL
  • H4 VM→맥미니 이전 진행 중 — 봇 작업 전 현재 primary 기기 확인
  • H5 @work 날짜 폴더(YYMMDD_*)는 동적 — 전역 grep 금지, 해당 <부류> 디렉토리만 한정 검색
  • H6 맥미니 정본은 맥미니에서 직접 작업(로컬 개발→scp 금지)
