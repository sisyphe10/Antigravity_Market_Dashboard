# 질문 — 한국 주식 일일 랭킹 데이터로 "매일 볼 만한" 인사이트 설계

개인 펀드매니저(한국 주식 롱온리 운용, 랩 상품 다수 운용)의 개인 대시보드 "Featured" 탭을 재설계 중이다.
지금까지 하루치 랭킹 표 7개만 나열해서 "열어봐도 볼 게 없다 / 읽어도 인사이트가 없다"는 평가를 받았다.
상단에 사전계산 인사이트 블록을 얹는 중인데, **어떤 지표가 실제로 매일 볼 만한지** 냉정하게 골라달라.

한국어로 답하라. 코드 말고 설계로 답하라.

## 1. 실제로 가진 데이터 (이것만 있다. 새 수집은 하지 않는다)

### A. 일별 랭킹 (2025-12-26 ~ 현재, 146거래일, 매 거래일 6종 × 각 TOP 30)
각 레코드: `{d, type, rank, name, code, market(KOSPI|KOSDAQ), trdval(거래대금 원), mktcap(시총 원), turnover(거래대금/시총), chg(등락률 %), price}`

`type` 6종:
- `absolute`   거래대금 TOP30
- `turnover`   거래대금/시총 비율(회전율) TOP30
- `kospi_cap`  코스피 시총 TOP30
- `kosdaq_cap` 코스닥 시총 TOP30
- `kospi_chg`  코스피 상승률 TOP30
- `kosdaq_chg` 코스닥 상승률 TOP30

★중요한 한계: **TOP30 밖은 데이터가 없다.** 전체 시장의 등락 종목수, 상승/하락 비율, 지수 값, 거래대금 총액 같은 시장 전체 집계는 이 데이터로 만들 수 없다. 시총 2,000억 미만·스팩·리츠·우선주는 애초에 필터로 빠진다.

### B. 신고가 (같은 기간, 매 거래일 가변 건수)
- `newhigh_20d` / `newhigh_120d` / `newhigh_52w` — 당일 고가가 과거 20/120/252 거래일 최고가를 넘은 종목
- 종목별 `lookback_used / lookback_target` (실제 확보된 이력 창 길이 — 신규 상장주는 짧다)
- 최근일 한정: 종목별 `theme` (뉴스 기반 LLM 촉매 키워드, 예 "MASGA", "HBM4 양산", "2분기 실적호조")와 테마별 설명

### C. 부가
- 종목코드 → WICS 업종(27개 산업군) 매핑 2,549건
- 종목코드 → 전종목 일별 고가·종가 히스토리 (yfinance 246일 시드 + KIS 63일 누적, 2,700종목)
- 사용자의 보유·관심 종목 3그룹(운용 중인 랩 편입 종목 16 + 15, 관심 4) — 총 35종목 내외
- 섹터별 뉴스 요약(당일, LLM 생성, 20일 신고가 기준)

### D. 참고 수치(2026-08-03 실측)
- 20일 신고가 79종목 / 120일 1종목 / 52주 0종목 (최근 20거래일 20일신고가 중앙값 36)
- 거래대금 TOP30 신규 진입 8종목·이탈 8종목
- 회전율 TOP30 20일 연속 등장 4종목
- 20일 신고가 업종 상위: 내구소비재와의류 11, 건강관리장비와서비스 10, 제약과생물공학 9

## 2. 지금 넣은 블록 (사용자 피드백 반영 후)

1. **신고가 온도** — 20일/120일/52주 건수 + 최근 20거래일 중앙값 + 완전이력 비율
2. **거래대금 TOP30 신규 진입·이탈** — 직전 거래일 대비 집합 차이
3. ~~회전율 TOP30 연속 등장~~ → **사용자가 빼라고 함** (자리가 하나 비었다)
4. **업종 쏠림** — 오늘 20일 신고가의 WICS 업종 분포 vs 직전 5거래일 평균
5. **보유·관심 레이더** — 보유·관심 종목이 오늘 어느 표에 등장했는지 (시총 TOP30은 대형주가 상시 등장해 제외, 신고가·상승률·회전율·거래대금만)

## 3. 물어보는 것

1. **위 5개(4개) 중 버릴 것이 있나?** 매일 보기에 정보가 없거나, 해석이 애매하거나, 오해를 부르는 것.
2. **빈 자리에 넣을 후보를 우선순위로 제안하라.** 반드시 위 A~C 데이터만으로 계산 가능해야 한다. 각 후보에 대해:
   - 정확한 계산 정의 (어떤 type, 어떤 창, 어떤 집계)
   - 이 지표가 답하는 질문 한 문장
   - 오해·함정 (표본이 작을 때, 대형주 편향, TOP30 절단 편향 등)
   - 2026-08-03 데이터에서 대략 어떤 값이 나올지 예상
3. **TOP30 절단(truncation) 편향을 어떻게 다룰지** — 예컨대 "TOP30 진입/이탈"은 30위 경계에서 미세한 차이로 들락거리는 잡음이 섞인다. 경계 잡음을 줄이는 정의가 있나?
4. **운용자 관점에서 이 데이터로 만들 수 있는데 내가 놓치고 있는 각도**가 있으면 지적하라. (예: 자금 집중도, 시장 폭, 테마 지속성, 대형주 vs 중소형주 로테이션 — 다만 TOP30만 있다는 한계를 반드시 감안할 것)
5. 남발하지 말 것. **최종 추천은 상단 블록 4~5개**로 좁혀라. 각각 왜 그것이 살아남았는지 한 줄.

## 4. 제약
- 화면에 설명문·안내문구를 넣지 않는다(사용자 규칙). 지표는 제목과 숫자만으로 읽혀야 한다.
- 표는 가운데 정렬, % 는 소수점 첫째자리, 금액은 억원 단위 `NN조 N,NNN억원`.
- 계산은 전부 생성기(파이썬)에서 사전계산하고 브라우저는 표시만 한다.
